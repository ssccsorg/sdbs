## Core Functions

### `tinylib.process(data)`

Process input data and return a result.

**Parameters:**

- `data` (str): Input data to process

**Returns:**

- `Result`: Processed result object

### `tinylib.analyze(result)`

Analyze a processed result.

**Parameters:**

- `result` (Result): Result from `process()`

**Returns:**

- `Analysis`: Analysis object with statistics
